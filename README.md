# ParkEase - Simple Vue Project

This project uses Vue 3 and Vite. Each main page has its own Vue component so the code is easier to read and edit.

## Pages
- Dashboard: `src/components/DashboardPage.vue`
- Register Parking: `src/components/RegisterPage.vue`
- Parking Slots: `src/components/ParkingSlotsPage.vue`
- Payments: `src/components/PaymentsPage.vue`
- Navigation and shared data/functions: `src/App.vue`
- Main CSS: `src/style.css`

## Run in VS Code
1. Extract this ZIP.
2. Open the `ParkEase_Separated` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal.

Records are saved in your browser using LocalStorage. No XAMPP or MySQL is needed.
